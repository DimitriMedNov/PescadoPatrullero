# Pescado Patrullero

Sitio web de una empresa pesquera, hecho como proyecto de la Universidad Anáhuac Mayab.

## Qué contiene

Tres páginas: la portada, la sección de quiénes son y la del equipo.

Los estilos están en una hoja propia (`src/styles.css`), escrita a mano y sin framework, que es justo lo que se estaba practicando.

## Stack

HTML · CSS
